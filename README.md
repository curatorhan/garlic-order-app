# 마늘귀신 주문 처리

주문처별 주문 파일을 올리면 옵션을 정제하고, 재고 범위 안에서 배정한 뒤
통합시트 · 패킹리스트 · 채널별 발송처리 파일을 만들어 줍니다.

## 배포 (Streamlit Community Cloud)

1. GitHub에 새 저장소를 만들고 이 파일들을 올립니다
2. share.streamlit.io 에 같은 GitHub 계정으로 로그인
3. New app → 저장소 선택 → Main file `app.py` → Deploy

## 화면

| 주소 | 화면 | 쓰는 사람 |
|---|---|---|
| 기본 URL | 주문 처리 (탭 4개) | CS |
| URL + `?view=stock` | 재고 입력 전용 | 배송팀 (태블릿) |

## 설정 시트

`config.py`의 `SHEET_URL`이 구글 시트 게시 주소입니다.
채널을 추가하거나 컬럼명이 바뀌면 **시트만 고치면 되고 코드는 건드리지 않습니다.**

| 칸 | 뜻 |
|---|---|
| 사용 | Y인 채널만 처리 |
| 헤더행 | 컬럼명이 몇 번째 줄에 있는지 |
| 판별컬럼 | 이 컬럼이 있으면 해당 채널로 인식 (채널끼리 겹치지 않게) |
| 고유키 | 주문을 식별하는 번호 컬럼 |
| 합배송키 | 같은 값이면 한 묶음 |
| 옵션 / 옵션보조 | 옵션이 비면 보조(보통 상품명)에서 찾음 |
| 옵션구분자 | 슬래시_뒤 · 슬래시_앞 · 하이픈_앞 · 없음 |
| 기본품종 / 기본꼭지 | 파일에서 못 찾을 때 쓰는 값 |
| 배정순위 | 재고 배정 시 채널 우선순위 |

## 처리 규칙

- **배정 우선순위** 업소용 → 주문일자(오래된 순) → 채널 → 주문시각
- **합배송** 채널 안에서만 묶고, 한 품목이라도 부족하면 묶음 전체 보류
- **보류 건** 발송 처리를 하지 않으므로 다음날 주문 파일에 다시 나옴
- **재고 SKU 19개** 중량은 재고에서 분리 (1·2·5·10kg이 모두 같은 재고에서 나감)
- **업소용** 깐마늘 5kg·10kg, 통합시트 옵션 칸 앞에 표시
- **하루 한 번** 아침 재고로 그날치를 처리

## 안전장치

- 설정 시트를 못 읽으면 중단
- 시트에 적힌 컬럼이 파일에 없으면 중단 (주문처 양식 변경 감지)
- 해석 못한 옵션이 있으면 중단하고 목록 표시
- 내려받기 전 검증 — 발송파일 행수 = 확정 행수, 주문번호 중복, 주소 누락

## 산출물

**통합시트** 주문번호 · 수령인명 · 연락처 · 옵션 · 수량 · 우편번호 · 주소 · 배송메세지 · 파일출처 · 등기번호
단건이 위, 합배송이 아래(이름순). 업소용 주황, 합배송은 묶음마다 노랑/파랑 교차.
등기번호는 우체국 업로드 후 채웁니다.

**패킹리스트** 확정분 품목별 수량과 총 kg

**채널별 발송처리** 원본 구조 그대로, 보류 행만 제외

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 화면 |
| `config.py` | 설정 시트 읽기, 재고 SKU 목록 |
| `core.py` | 옵션 파싱, 파일 적재, 재고 배정 |
| `build.py` | 산출물 생성, 검증 |
| `requirements.txt` | 필요한 라이브러리 |
